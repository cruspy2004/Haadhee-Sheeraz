# Memetent

Compilation game in Java (Swing/JavaFX). Added responsive memes to classic
games. 60% boost in interaction, 14% higher click-through.

## How HR reads it

Coursework-shaped. Java + Swing signals "university project" to anyone
who's hired before, and neither lane you're targeting uses that stack.

The metrics are the interesting part — 60% and 14% imply you **measured**
a behavioural change, which most student projects never do. That's the
only line worth keeping.

## Verdict

Keep it on the site (it's real, it shipped, five projects is a healthier
number than four) but rank it **last** and don't lead with it in
conversation. If asked, tell the measurement story, not the Java story.

Serves: neither lane directly. Filler with one good line.
