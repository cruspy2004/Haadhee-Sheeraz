# TopicPulse

Content-gap finder for Medium writers. Scrapes Stack Overflow for
high-demand, low-answer questions, runs sentiment analysis on existing
Medium articles, ranks underserved topics by demand and gap size.

Python, Flask, NLP. Live on Vercel, code on GitHub.
